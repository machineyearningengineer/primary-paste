# Media rights

## Current product media

| Asset | Origin | Rights |
| --- | --- | --- |
| App icon and `icon.png` | AppKit shapes drawn by `Scripts/generate_app_icon.swift`; no imported image | Original artwork; GPL-3.0-only |
| `onboarding.png`, `first-paste.png` | Own app and local fixture, captured in disposable macOS guest | Original app/fixture content; incidental Apple UI retains its owner’s rights |
| Demo, hero and editable source | Recorded Safari → TextEdit interaction, original synthetic text, native editable labels/cursor | Original edit/fixture/overlays; GPL-3.0-only, with Apple UI rights retained |
| Figtree font | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/figtree) | SIL OFL; [license included](Explainer/FONT-LICENSE.txt) |

No stock imagery, customer data, music, endorsements or generated bitmap art is used in the current product media. Recordings are actual interactions; timing and framing may be edited for clarity.

The optional Platform Bridge variant now uses original window outlines and a transfer arrow. Platform mascots and Finder-like artwork are no longer in the app renderer.

## Private archive

Legacy concept/reference images have no verified external license metadata. They are not adopted as GPL artwork. Historical design previews, QA screenshots and internal workflow notes are preserved privately, outside the publication tree.

The public source candidate has a clean initial commit and contains none of the old `Design/` or `.workflow/` material. The original GitHub repository/history stays private when the owner publishes the fresh source repository. Product source archives contain the same reviewed source tree.
