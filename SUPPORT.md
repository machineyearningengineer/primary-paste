# Support

Start with [Your first paste](Docs/GettingStarted.md), [Installation](Docs/Install.md) and [Compatibility](Docs/Compatibility.md). The app's menu opens Setup again; General → Advanced can expose Support checks when needed.

For unexpected behavior, search [existing issues](https://github.com/machineyearningengineer/primary-paste/issues), then file a bug with a small synthetic reproduction. Include app and macOS versions, capture/clipboard modes, permission status and relevant app rules. Remove private data from screenshots and reports.

Support is maintainer-led and best-effort. There is no paid support plan or response-time guarantee. Security reports use [SECURITY.md](SECURITY.md).
